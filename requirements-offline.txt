# =============================================================================
# requirements-offline.txt
# 폐쇄망(Air-gapped) 서버에서의 오프라인 설치 가이드
# =============================================================================
#
# 이 파일은 wheelhouse 를 활용한 오프라인 패키지 설치 방법을 안내합니다.
# 실제 pip -r 로 사용하는 requirements 파일이 아니며, 안내 문서입니다.
#
# =============================================================================
# 1. 준비 (인터넷 연결된 환경)
# =============================================================================
#
#   # 전체 deps 세트 다운로드 및 패키지 생성
#   bash scripts/run-all.sh --clean
#
#   # 특정 세트만
#   bash scripts/run-all.sh --modules=deps/fastapi-server --clean
#
#   # 생성된 파일: output/wheelhouse_<YYYYMMDD_HHmmss>.tar.gz
#
# =============================================================================
# 2. 폐쇄망 서버로 전송
# =============================================================================
#
#   # scp 예시
#   scp output/wheelhouse_*.tar.gz user@airgapped-server:/opt/
#
#   # 또는 USB/물리 매체로 전달
#
# =============================================================================
# 3. 폐쇄망 서버에서 압축 해제
# =============================================================================
#
#   # tar.gz 해제
#   tar -xzf /opt/wheelhouse_20250316_143022.tar.gz -C /opt/
#   # → /opt/wheelhouse/ 디렉터리 생성
#
#   # zip 해제 (--format=zip 으로 생성한 경우)
#   unzip /opt/wheelhouse_20250316_143022.zip -d /opt/
#
# =============================================================================
# 4. 오프라인 설치
# =============================================================================
#
#   # 단일 패키지 설치
#   pip install --no-index --find-links=/opt/wheelhouse fastapi
#
#   # requirements.txt 기반 전체 설치
#   pip install --no-index --find-links=/opt/wheelhouse -r requirements.txt
#
#   # 특정 버전 지정
#   pip install --no-index --find-links=/opt/wheelhouse "fastapi>=0.115.0"
#
#   # 가상 환경에 설치
#   python -m venv .venv
#   source .venv/bin/activate  # Windows: .venv\Scripts\activate
#   pip install --no-index --find-links=/opt/wheelhouse -r requirements.txt
#
# =============================================================================
# 5. 설치 확인
# =============================================================================
#
#   pip list
#   python -c "import fastapi; print(fastapi.__version__)"
#
# =============================================================================
# 주의사항
# =============================================================================
#
#   - wheelhouse 는 특정 OS/아키텍처/Python 버전에 맞는 .whl 파일을 포함합니다.
#     폐쇄망 서버의 환경(OS, CPU, Python 버전)과 다운로드 환경이 일치해야 합니다.
#
#   - Python 버전 지정: bash scripts/run-all.sh --python=3.11
#
#   - 플랫폼 불일치 시 소스 패키지(.tar.gz)가 포함될 수 있으며,
#     이 경우 서버에 C 컴파일러(gcc)가 필요할 수 있습니다.
#
#   - 가능하면 인터넷 환경과 폐쇄망 서버의 OS/아키텍처를 맞추는 것을 권장합니다.
#     (예: 둘 다 Linux x86_64, Python 3.11)
